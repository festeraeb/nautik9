🌍 God's Eye
Measuring this phone...

The frame rate is this phone drawing this globe for a short probe; no figure for the home GPU is measured here, so none is claimed. The thresholds are settings (Settings tab), not fixed rules.

📍 Track this phone

When this is on, and only while this tab is showing, the phone's position (latitude, longitude, altitude, accuracy, heading, speed and the time) is sent every few seconds, over Tailscale only, to the home track service, which keeps the latest few hundred fixes in memory and shows them on the globe. Nothing is saved on the phone except this switch. It is off until you turn it on.

Globe

Aerial imagery from Esri World Imagery, drawn with CesiumJS. The stream is view-only. The full God's Eye app (many more layers) is at its own address, not inside this tab.
